Ez a projekt a szakdolgozatomhoz készült interaktív 3D alkalmazás, amely a vetületi torzulások szemléltetését támogatja. Az alkalmazás C# nyelven, WPF környezetben és Helix Toolkit használatával készült. A program egy 3D földgömbön jeleníti meg a kontinensek pontadatait, majd különböző síkvetületi eljárások segítségével mutatja be, hogyan torzulnak az alakok, távolságok és területek a síkba vetítés során.
Az alkalmazás célja, hogy oktatási segédeszközként könnyebben érthetővé tegye a térképi vetületek működését és a vetületi torzulások jelenségét.
